🐉 KILL MONSTER — The Battle RPG

A simple text-based RPG game made with Python for fun and practice. This is my first long Python program, created by combining concepts learned from my college syllabus and my own coding knowledge.
_________________________________________

🎮 How to Play

Run the game:

python KILL_MONSTER_The_Battle_RPG.py

Controls:

- "M" — Select Mage
- "W" — Select Warrior
- "S" — Start the battle
- "A" — Attack the dragon
- "D" — Attempt to dodge an incoming dragon attack

Objective: Defeat the dragon before your HP reaches zero!
_________________________________________

⚔️ Characters

- Warrior: 10 HP | 2 Attack | Mystic Sword
- Mage: 15 HP | 1 Attack | Magic Wand

The dragon has 40 HP and deals random damage between 2 and 4 HP.

Python Classes, Functions, Loops, Conditionals, Random Module, Threading, and more.
